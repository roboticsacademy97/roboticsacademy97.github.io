# AGENTS.md — інструкції для AI-агентів

Сайт Академії робототехніки 97 (RA97) ліцею № 97, Дніпро. Репозиторій ведуть двоє викладачів через pull request.
Цей файл — єдине джерело правил для агентів; `CLAUDE.md` лише підключає його. Змінюються правила чи схема даних — онови цей файл у тому ж PR.

## Головне

1. Ніколи не пушити в `main`. Тільки гілка → pull request → зелена перевірка **Check** → злиття людиною.
2. Перед кожним PR `npm run build` має пройти без помилок.
3. Агент не зливає PR сам, навіть якщо має права, — лише коли людина прямо про це попросила.
4. Учні неповнолітні. На сайті вони — тільки «Ім’я П.», без фото, класу й контактів. Бали рубрики 0–4 не публікуємо.
5. Відповіді до діагностики, захисні запитання з варіантами і тести-еталони в цей (публічний) репозиторій не кладемо.
6. Не вигадуй фактів: дат, годин, імен, результатів, посилань. Чого бракує — питай.
7. Текст сайту українською. Терміни англійською — у дужках при першій появі; код і коментарі в коді — як прийнято в мові.
8. Один PR — одна зміна: модуль, паспорт, правка дизайну.
9. Жодних секретів і ключів у репозиторії.

## З ким працюєш

Зазвичай — викладач (Сергій або його колега, учитель інформатики), іноді учень. Відповідай мовою повідомлення людини, а текст для сайту пиши українською.

## Стек і команди

- Astro 7 + Starlight, Node.js 24 (`.nvmrc`). TypeScript закріплено на `^6`: `astro check` ще не підтримує TS 7.
- Звичайний CSS (`src/styles/ra97.css`), без Tailwind і CMS. Шрифти — локально через `@fontsource`, без Google Fonts: сайт має працювати офлайн.
- Бренд: graphite `#1F1E1D`, signal `#F45300` (текстом на світлому — лише `#C84300`), заголовки Russo One (тільки вага 400), текст Manrope, код JetBrains Mono. Скруглень немає, лише фаски 45°.

```sh
npm ci
npm run dev            # http://localhost:4321
npm run build          # те саме, що Check на PR
npm run check:program  # лише перевірка програми
```

## Програма як дані

Карта програми, сторінки курсів і таблиці модулів збираються з `src/data/`:

- `courses.yaml` — курси: код (ПРГ), slug (prg), назва, трек, список модулів, версія паспорта;
- `modules.yaml` — модулі: код (ПРГ1), slug (prg1), курс, назва, теми, рік, пререквізити, години, хто проходить; для курсів із паспортом — результати, бейдж, екстерн;
- `plan-a.yaml` — повний шлях: рік 0, слот Ф за роками, слот Т кожної ролі.

Схеми полів — у `src/content.config.ts`. Перехресні перевірки — у `scripts/check-program.mjs`: пререквізит існує, циклів немає, у шляху ролі модуль стоїть пізніше за свої пререквізити, у блоці не більше двох модулів. Якщо перевірка падає — виправ дані, а не скрипт.

Код у тексті — кирилицею (ПРГ1, МАТ1.2), в адресі — латиницею: `/kursy/prg/#prg1`. Адреси не міняємо після публікації.

## Де що лежить

```
src/content/docs/index.mdx        головна
src/content/docs/pro.md           про академію (стисла Концепція)
src/content/docs/vstup.md         вступ, екстерн, діагностика
src/content/docs/programa/        Карта (index.mdx) і пілотний набір 2026 (pilot.md)
src/content/docs/kursy/<slug>/    паспорт курсу; без цієї теки сторінку курсу генерує src/pages/kursy/[course].astro
```

Коли пишеться паспорт курсу: створи `src/content/docs/kursy/<slug>/index.mdx`, додай `passport: v0.1` курсу в `courses.yaml`, а результати й бейджі модулів — у `modules.yaml`.
