## Як працювати

1. Прочитай сторінку заняття і повтори приклади в REPL або у файлі.
2. Відкрий файл вправ, напиши тіло функції замість `raise NotImplementedError`.
3. Запусти тести заняття. Червоне — читай, що функція повернула і що мала повернути, виправляй. Зелене — наступна вправа.
4. Застряг більш як на 15 хвилин — запиши, що пробував, і спитай викладача або сусіда. Не готову відповідь, а підказку.

**Без ШІ.** На заняттях ПРГ1 ШІ-помічники вимкнені: синтаксис має пройти через твої руки (див. [Положення про бейджі](/polozhennia/#ші-помічники)). На захисті ти змінюєш свій код наживо, і код, який ти не можеш пояснити, не зараховується.

## Що потрібно

- Ноутбук із Windows 11, VS Code з розширеннями Python і Ruff, `uv`. Усе — з флешки академії.
