## while: поки умова істинна

```python
level = 90
minutes = 0
while level < 100:
    level = level + 3
    minutes = minutes + 1
print(minutes)   # 4
```

Тіло повторюється, поки умова істинна. Щось у тілі **має** наближати умову до хибності, інакше цикл нескінченний. Завис — **Ctrl+C** у терміналі.

## for і range: для кожного

```python
for i in range(5):          # 0, 1, 2, 3, 4 — п'ять чисел, останнє не входить
    print(i)

for i in range(1, 4):       # 1, 2, 3
    print(i)

for i in range(10, 0, -3):  # 10, 7, 4, 1 — крок може бути від'ємним
    print(i)
```

`for` береш, коли знаєш, по чому йдеш (числа, символи рядка). `while` — коли знаєш лише умову зупинки.

## Лічильник і накопичувач

Два шаблони, які трапляються в половині програм:

```python
commands = "FFLFRF"

count = 0                  # лічильник: починаємо з нуля
for c in commands:
    if c == "F":
        count += 1         # те саме, що count = count + 1

result = ""                # накопичувач: починаємо з «порожнього»
for c in commands:
    result = c + result    # щоразу додаємо до того, що вже є
print(count, result)       # 4 FRFLFF
```

## break і continue

- `break` — вийти з циклу зараз, решту не перевіряти.
- `continue` — пропустити решту тіла і перейти до наступного кроку.

```python
for c in "ab3c":
    if c.isdigit():
        print("перша цифра:", c)
        break
```

## Рядок як послідовність

Рядок — послідовність символів з номерами-**індексами**, що починаються з **нуля**.

```python
>>> s = "ESP32-S3"
>>> s[0], s[3], s[-1]        # перший, четвертий, останній
('E', '3', '3')
>>> len(s)
8
>>> s[0:3]                   # зріз: з 0 до 3, останній не входить
'ESP'
>>> s[-2:]                   # два останні
'S3'
>>> s[::-1]                  # увесь рядок задом наперед
'3S-23PSE'
>>> "32" in s
True
```

Обійти рядок можна по символах (`for c in s`) або по індексах (`for i in range(len(s))`). Індекси потрібні, коли важливо, **де** стоїть символ.

Рядки **незмінні**: `s[0] = "e"` — помилка. Новий рядок будують накопичувачем або зрізами.
