## if, elif, else

```python
distance_cm = 15

if distance_cm > 20:
    print("вперед")
elif distance_cm > 5:
    print("повільно")
else:
    print("стоп")
```

- Після умови — **двокрапка**, тіло — з **відступом** у 4 пробіли. Відступ у Python — частина синтаксису, а не прикраса.
- Умови перевіряються згори вниз, виконується **перша** істинна гілка, решта пропускаються.
- `elif` і `else` — необов'язкові.

## Порівняння

`==` (дорівнює), `!=` (не дорівнює), `<`, `<=`, `>`, `>=`. Результат — `True` або `False`.

```python
>>> 3.7 <= 3.85 < 4.0     # подвійне порівняння, як у математиці
True
>>> "ровер" == "Ровер"     # рядки порівнюються з урахуванням регістру
False
```

Не плутай `=` (присвоїти) і `==` (порівняти).

## and, or, not

| Вираз | Істинний, коли |
| --- | --- |
| `a and b` | обидва істинні |
| `a or b` | хоча б один істинний |
| `not a` | `a` хибний |

```python
is_dark = light_lux < 50
obstacle_near = distance_cm < 30
if is_dark and obstacle_near:
    print("увімкнути фари і пригальмувати")
```

Складну умову зручно розбити на змінні з іменами, як вище: її легше читати і перевіряти.

## Межі

Найчастіша помилка в умовах — на межі. «Від 3,7 В — нормальний»: що буде при рівно 3,7? `>` чи `>=`? Перш ніж писати, **випиши межові значення** і що має вийти для кожного. Тести до вправ перевіряють саме межі.

## Чому float не порівнюють через ==

```python
>>> 0.1 + 0.2 == 0.3
False
>>> abs((0.1 + 0.2) - 0.3) < 1e-9
True
```

Числа з комою комп'ютер зберігає у двійковому вигляді наближено: 0,1 у двійковій системі — нескінченний дріб, як 1/3 у десятковій. Тому float порівнюють «з допуском»: чи різниця менша за малу величину. Для вимірів допуском зазвичай є похибка (див. [ФІЗ-експрес](/kursy/fiz/ekspres/2-pokhybky/)).
