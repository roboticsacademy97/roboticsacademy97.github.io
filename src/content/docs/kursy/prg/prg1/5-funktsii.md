## Що таке функція

Функція — іменований шматок коду: отримує дані через **параметри**, повертає результат через **return**.

```python
def led_current_ma(r_ohm, u_led=2.0, u_supply=5.0):
    """Струм через світлодіод у міліамперах."""
    return (u_supply - u_led) / r_ohm * 1000


i = led_current_ma(220)                 # u_led і u_supply — за замовчуванням
j = led_current_ma(470, u_led=1.9)      # параметр за іменем
```

- `def`, ім'я, параметри в дужках, двокрапка, тіло з відступом.
- **Параметри за замовчуванням** (`u_led=2.0`) можна не передавати.
- Рядок у потрійних лапках одразу після `def` — **docstring**: що робить функція. Його показує VS Code, коли наводиш мишку на виклик.
- `return` завершує функцію **негайно**. Функція без `return` повертає `None`.

## return і print — не одне й те саме

```python
def area_print(a, b):
    print(a * b)      # показує людині, але нікому не віддає


def area(a, b):
    return a * b      # віддає значення тому, хто викликав


total = area(2, 3) + area(4, 5)        # 26
total = area_print(2, 3) + 1           # TypeError: None + 1
```

Функції, з якими працює інший код (і тести), **повертають** значення. `print` — лише в головній програмі, для людини.

## Область видимості

Змінні, створені всередині функції, — **локальні**: їх не видно ззовні, і вони зникають, коли функція завершується. Функція бачить лише свої параметри, свої змінні і глобальні імена (константи на кшталт `NORTH = 0`).

```python
def f():
    x = 5
    return x


f()
print(x)   # NameError: x існує лише всередині f
```

Тому все, що функції потрібно, передаємо **параметрами**, а все, що вона має віддати, — через **return**. Така функція не залежить від решти програми, і її можна протестувати окремо.

## Декомпозиція

Велику задачу ділимо на функції, кожна з яких робить **одну річ** і має ім'я, що це каже. Потім збираємо з них рішення.

Задача: «перетвори швидкості двох моторів у відсотках на команду `L128 R-255`».

1. Обмежити число межами — `clamp`.
2. Відсотки → значення ШІМ (широтно-імпульсної модуляції) — `pwm_from_percent`, використовує `clamp`.
3. Зібрати рядок команди — `motor_command`, двічі викликає `pwm_from_percent`.

Кожну функцію пишемо й тестуємо окремо, знизу вгору. Помилка в `clamp` проявиться в тестах `clamp`, а не загубиться в `motor_command`.

Так само влаштований Ровер: `turn_left`, `turn_right`, `step`, `inside` — маленькі функції, а `run` лише збирає їх у цикл.
