**1 год · вправи: `u6_nalahodzhennia.py`.**

## Що всередині тесту

Відкрий `tests/test_u3.py`:

```python
def test_sign(x, expected):
    assert sign(x) == expected
```

`assert умова` нічого не робить, якщо умова істинна, і зупиняє тест з помилкою, якщо хибна. Тест — це функція, ім'я якої починається з `test_`. pytest знаходить такі функції у файлах `test_*.py` і запускає по черзі. `@pytest.mark.parametrize` запускає той самий тест для кількох наборів даних.

У ПРГ1 тести готові: їх написали викладачі за умовою. Власні тести ти писатимеш з ПРГ2.

## Звіт pytest

```text
FAILED tests/test_u6.py::test_percent[1-2-50.0] - assert 0 == 50.0 ± 5.0e-05
```

- **Який тест:** файл, функція і в квадратних дужках — набір даних (`part=1, whole=2, expected=50.0`).
- **Що сталося:** функція повернула `0`, а мала `50.0`.

Корисні прапорці: `uv run pytest -x` — зупинитися на першій помилці; `uv run pytest -k percent` — лише тести, в імені яких є `percent`; `uv run pytest -v` — докладний список.

## Налагоджувач

Налагоджувач (debugger) зупиняє програму на потрібному рядку і показує значення всіх змінних. Це швидше, ніж вставляти `print` скрізь.

1. **Точка зупинки:** клікни ліворуч від номера рядка — з'явиться червона крапка.
2. **Запуск:** у бічній панелі Testing (колба) біля тесту — кнопка **Debug Test**. Або для програми — F5.
3. Програма зупиниться на точці. Ліворуч — панель **Variables** з усіма змінними.
4. Керування:
   - **F10** (Step Over) — виконати рядок;
   - **F11** (Step Into) — зайти всередину функції, яку викликає рядок;
   - **Shift+F11** (Step Out) — вийти з функції;
   - **F5** (Continue) — до наступної точки зупинки.
5. **Watch** — додай вираз (наприклад, `total / seconds`), і він перераховуватиметься на кожному кроці.

Метод пошуку помилки: **передбач**, яке значення має бути в змінній на цьому кроці, і порівняй з тим, що показує налагоджувач. Перше розходження — там і помилка.

## Вправи

Тести: `uv run pytest tests/test_u6.py`. У файлі `u6_nalahodzhennia.py` три функції, у кожній — **одна** помилка. Тести вже червоні.

1. Для кожної функції: постав точку зупинки, запусти тест у налагоджувачі, пройди крок за кроком і знайди рядок, де значення розходиться з твоїм передбаченням.
2. Виправ **лише помилку**, не переписуючи функцію.
3. У коментарі над виправленим рядком запиши, як ти її знайшов: на якому кроці і яке значення тебе насторожило.

На захисті Ровера викладач попросить показати в налагоджувачі конкретний момент роботи твоєї програми — потренуйся тут.
