## Змінна

Змінна — ім'я, прив'язане до значення. `=` означає «присвоїти», а не «дорівнює».

```python
capacity_mah = 1000
current_ma = 600
current_ma = current_ma + 50   # праву частину обчислюємо, потім прив'язуємо ім'я до результату
```

Імена — латиницею, малими літерами, слова через `_`: `cell_voltage`, `wheel_diameter_mm`. Одиницю варто вписати в ім'я: `distance_cm` не сплутаєш із `distance_m`.

## Чотири базові типи

| Тип | Приклади | Що це |
| --- | --- | --- |
| `int` | `42`, `-3`, `0` | ціле число, будь-якої довжини |
| `float` | `3.7`, `0.1`, `2e-3` | число з комою (у коді — **крапка**) |
| `str` | `"ровер"`, `'F'`, `""` | рядок тексту |
| `bool` | `True`, `False` | істина або хиба |

```python
>>> type(3.7)
<class 'float'>
>>> 7 / 2       # ділення завжди дає float
3.5
>>> 0.1 + 0.2   # float — наближене число
0.30000000000000004
```

## Арифметика: // і %

| Операція | Приклад | Результат |
| --- | --- | --- |
| `/` ділення | `7 / 2` | `3.5` |
| `//` цілочисельне ділення | `7 // 2` | `3` |
| `%` остача від ділення | `7 % 2` | `1` |
| `**` степінь | `2 ** 10` | `1024` |

`//` і `%` — пара: `125 // 60` — скільки повних хвилин, `125 % 60` — скільки секунд лишилося. `n % 2 == 0` — перевірка на парність. Остача ще знадобиться в Ровері: напрям 0–3 після повороту — це остача від ділення на 4.

## Перетворення типів

```python
>>> int("42") + 1
43
>>> float("3.7")
3.7
>>> str(1000) + " мА·год"
'1000 мА·год'
>>> int(3.99)    # відкидає дробову частину, а не округлює
3
>>> round(3.99)
4
```

`int("80%")` — помилка `ValueError`: у рядку не лише цифри.

## input і print

```python
name = input("Як звати робота? ")      # input ЗАВЖДИ повертає рядок
speed = int(input("Швидкість, %: "))   # число — лише після перетворення
print("Робот", name, "їде зі швидкістю", speed, "%")
```

## f-рядки

f-рядок підставляє значення у фігурні дужки і вміє їх форматувати:

```python
>>> u = 2.857
>>> f"U_R = {u} В"
'U_R = 2.857 В'
>>> f"U_R = {u:.1f} В"       # один знак після коми
'U_R = 2.9 В'
>>> s = 5
>>> f"{s:02d} с"             # ціле, щонайменше дві цифри, доповнити нулем
'05 с'
```
