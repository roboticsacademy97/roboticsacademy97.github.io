## Python, інтерпретатор, uv

Python — **інтерпретована** мова: програму не перетворюють заздалегідь на файл `.exe`, а інтерпретатор `python` читає й виконує її рядок за рядком. Тому помилку в 10-му рядку ти побачиш лише тоді, коли виконання до нього дійде.

`uv` — менеджер проєкту: ставить потрібну версію Python і пакети (pytest, ruff) окремо для кожного проєкту, щоб вони не заважали один одному. Тобі вистачить однієї команди: `uv run <що запустити>`.

## Відкрий вправи

1. Розпакуй [prg1-vpravy.zip](/shablony/prg1-vpravy.zip) у свою теку, наприклад `Документи\ra97\prg1-vpravy`.
2. У VS Code: File → Open Folder → обери теку `prg1-vpravy`. Погодься встановити рекомендовані розширення (Python, Ruff), якщо VS Code запропонує.
3. Відкрий термінал: Terminal → New Terminal. Він відкриється одразу в теці проєкту.

```sh
uv run python --version     # перший запуск сам поставить Python 3.13, pytest і ruff
```

## REPL: Python у режимі розмови

```sh
uv run python
```

Запрошення `>>>` означає: Python чекає на рядок коду і відразу показує результат.

```python
>>> 2 + 3 * 4
14
>>> 7 / 2
3.5
>>> "ровер" * 3
'роверроверровер'
>>> exit()
```

REPL — для того, щоб швидко щось перевірити. Програму пишемо у файлі.

## Скрипт

Відкрий `u1_pryvit.py`. Унизу файла:

```python
if __name__ == "__main__":
    print(greeting())
```

Цей блок виконується, коли файл запускають як програму. Запусти:

```sh
uv run u1_pryvit.py
```

Отримаєш помилку `NotImplementedError`: функцію ще не написано. Заміни `raise NotImplementedError` на `return "Привіт, RA97!"` — і запусти знову.

## Перший тест

```sh
uv run pytest tests/test_u1.py
```

Тест викликає твою функцію і перевіряє відповідь. Зелене `1 passed` — функція робить те, що треба. У наступних заняттях кожна вправа має свої тести, і вони — твій перший рецензент коду.

## Помилка — це підказка

Коли програма падає, Python друкує **traceback** — звіт про те, де і що сталося. Читай його **знизу вгору**:

```text
Traceback (most recent call last):
  File "C:\...\prg1-vpravy\u1_traceback.py", line 12, in <module>
    print("Ємність акумулятора: " + capacity_mah + " мА·год")
          ~~~~~~~~~~~~~~~~~~~~~~~~^~~~~~~~~~~~~~
TypeError: can only concatenate str (not "int") to str
```

1. **Останній рядок** — тип помилки і пояснення: `TypeError` — операція з невідповідними типами; «не можна склеїти рядок із цілим числом».
2. **Вище** — файл і номер рядка (`line 12`) і сам рядок, де сталося. Знаки `^` показують місце.
3. Якщо функція викликала функцію, рядків «File …» буде кілька: найнижчий — де впало, вищі — хто кого викликав.

Часті помилки:

| Помилка | Що означає |
| --- | --- |
| `SyntaxError` | Python не зміг прочитати рядок: пропущена дужка, лапка чи двокрапка |
| `IndentationError` | неправильний відступ |
| `NameError` | ім'я не визначене: опечатка або змінну ще не створено |
| `TypeError` | операція з невідповідними типами |
| `ValueError` | тип правильний, а значення ні: `int("80%")` |
| `ZeroDivisionError` | ділення на нуль |
