## Шляхи і навігація

Файлова система Linux — одне дерево з коренем `/`. Дисків C: і D: немає: усе вкладене в `/`.

| Команда | Що робить |
| --- | --- |
| `pwd` | показує, де ти зараз |
| `ls`, `ls -l`, `ls -a` | вміст теки; докладно; разом із прихованими файлами (ім'я з крапки) |
| `cd laby/2026-11` | перейти за **відносним** шляхом — від поточної теки |
| `cd /home/ra97/praktyka` | перейти за **абсолютним** шляхом — від кореня `/` |
| `cd ..`, `cd ~`, `cd -` | на рівень вище; додому; туди, де був щойно |
| `tree` | дерево теки |

**Tab** доповнює імена файлів і команд. Двічі Tab — показує варіанти. Стрілка вгору — попередня команда, **Ctrl+R** — пошук в історії команд. **Ctrl+C** — зупинити команду, яка зависла.

## Файли й теки

| Команда | Що робить |
| --- | --- |
| `mkdir -p a/b/c` | створити теку (разом із проміжними) |
| `touch notatky.md` | створити порожній файл |
| `cp файл копія`, `cp -r тека копія` | копіювати файл; теку |
| `mv старе нове` | перейменувати або перемістити |
| `rm файл`, `rm -r тека` | видалити **назавжди**, без кошика |
| `cat`, `less`, `head -n 5`, `tail -n 5` | показати файл; гортати (вихід — `q`); перші й останні рядки |
| `nano файл` | простий редактор: Ctrl+O — зберегти, Ctrl+X — вийти |

Ім'я з пробілом бери в лапки: `cat "chernetky/нотатки 1.txt"`. А краще не став пробіли в іменах своїх файлів.

## Права

`ls -l` показує на початку рядка щось на кшталт `-rw-r--r--`: права власника, групи й усіх інших на читання (r), запис (w) і виконання (x).

```bash
ls -l roboty/rover/start.sh
./roboty/rover/start.sh          # Permission denied — немає права на виконання
chmod +x roboty/rover/start.sh   # додати право на виконання
./roboty/rover/start.sh
```

## Пошук: find і grep

```bash
find . -name "*.csv"              # усі CSV у поточній теці й глибше
find . -type d                    # лише теки
grep ERROR logy/rover-2026-11-01.log    # рядки зі словом ERROR
grep -r -n "крок 11" logy         # рекурсивно, з номерами рядків
grep -c ERROR logy/*.log          # скільки рядків з ERROR у кожному файлі
```

`*` — шаблон: «будь-які символи». Його розкриває сам термінал до запуску команди.

## Конвеєри й перенаправлення

Найсильніша ідея терміналу: маленькі команди з'єднуються в ланцюжок, і вихід однієї стає входом наступної.

| Запис | Що робить |
| --- | --- |
| `a \| b` | вихід `a` — на вхід `b` (конвеєр, pipe) |
| `a > файл` | вихід у файл, **перезаписує** його |
| `a >> файл` | дописує в кінець файла |
| `a 2> помилки.txt` | повідомлення про помилки — у файл |

```bash
cat logy/*.log | grep ERROR | wc -l               # скільки помилок за три дні
sort -n roboty/manipuliator/kuty.txt | uniq        # кути без повторів, за зростанням
sort -n roboty/manipuliator/kuty.txt | uniq -c     # скільки разів трапився кожен кут
grep WARN logy/*.log > poperedzhennia.txt          # зберегти попередження у файл
```
