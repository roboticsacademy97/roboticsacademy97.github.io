**1,5 год.** WSL2 (Windows Subsystem for Linux) запускає справжнє ядро Linux усередині Windows. У ньому ти працюватимеш з терміналом і Git зараз, з C++ у ПРГ3 і з ROS 2 пізніше.

Ми ставимо Ubuntu не з інтернету, а з **образу на флешці академії**: у ньому вже є git, ssh, tree, nano і все потрібне для модуля. Так установлення займає хвилини і працює, навіть коли інтернет вимкнули.

## Перевір, що WSL увімкнено

Відкрий **PowerShell** (Win → набери «PowerShell» → Enter) і виконай:

```powershell
wsl --version
```

Бачиш версію WSL — усе гаразд. Бачиш помилку чи пропозицію встановити — клич викладача: першу установку WSL робить він, з правами адміністратора.

## Імпортуй Ubuntu з флешки

Встав флешку і подивись у Провіднику, яку літеру вона отримала (нижче це `D:`). Образ лежить у теці `ra97`.

```powershell
mkdir $env:USERPROFILE\wsl
wsl --import ra97 $env:USERPROFILE\wsl\ra97 D:\ra97\ra97-ubuntu-2404.tar
wsl --set-default ra97
wsl --list --verbose
```

- `wsl --import` створює новий Linux з архіву: ім'я (`ra97`), тека, де він житиме на диску, і сам архів.
- Якщо ноутбуком користуються кілька учнів, назви свій Linux своїм ім'ям латиницею: `ra97-ivan`.
- `wsl --list --verbose` має показати `ra97` з `VERSION 2`.

Запусти:

```powershell
wsl
```

Запрошення змінилося на щось на кшталт `ra97@ноутбук:~$` — ти в Linux. Вийти — `exit`.

:::tip[Є інтернет?]
Можна поставити Ubuntu з магазину: `wsl --install -d Ubuntu-24.04`. Але тоді все, що є в образі академії (git, ssh, tree), доведеться ставити самому через apt. Для занять бери образ.
:::

## Перші команди

```bash
whoami                 # хто я
pwd                    # де я
cat /etc/os-release    # яка це система
uname -r               # версія ядра: у назві має бути WSL2
```

Пароль користувача `ra97` скаже викладач. Він потрібен для `sudo` — команд від імені адміністратора Linux. Коли вводиш пароль, символи не показуються: це нормально.

## Пакунки: apt

У Linux програми ставлять з репозиторіїв (сховищ пакунків) менеджером пакунків. В Ubuntu це `apt`.

```bash
sudo apt update             # оновити список пакунків (потрібен інтернет)
apt list --installed | wc -l # скільки пакунків уже стоїть
sudo apt install cowsay     # поставити пакунок
/usr/games/cowsay "Привіт, RA97"
```

Немає інтернету — `apt update` скаже, що не може з'єднатися. Тоді пропусти встановлення: усе, що потрібно для модуля, вже є в образі.

## Файли Windows і Linux

- Твоя домашня тека в Linux — `~` (тобто `/home/ra97`). **Працюй тут**: файли Linux у файловій системі Linux працюють швидко і без проблем із правами.
- Диски Windows видно в Linux як `/mnt/c`, `/mnt/d`. Твоя тека Windows — `/mnt/c/Users/<ім'я_в_Windows>`.
- Відкрити поточну теку Linux у Провіднику: `explorer.exe .`
- У Провіднику файли Linux — у розділі **Linux** зліва або за адресою `\\wsl.localhost\ra97\home\ra97`.

## VS Code і WSL

1. У VS Code встанови розширення **WSL** (з флешки: Extensions → `…` → Install from VSIX).
2. У терміналі Linux перейди в теку проєкту і виконай `code .` — VS Code відкриє її «всередині» Linux, а вбудований термінал буде терміналом Ubuntu.

## Якщо WSL2 не стає

Працюєш у **Git Bash** (Win → «Git Bash»). Це не Linux, а набір тих самих команд для Windows:

- `apt` і `sudo` немає: усе потрібне вже входить у Git for Windows;
- диски — `/c`, `/d` замість `/mnt/c`, `/mnt/d`;
- домашня тека — твоя тека Windows (`/c/Users/<ім'я>`).

Решта модуля — термінал, ssh, git, Markdown — однакова.
