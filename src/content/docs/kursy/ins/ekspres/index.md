:::note[Лише для пілотного набору 2026]
ІНС-експрес замінює ІНС1 і ІНС2 для нинішніх 10-класників. Набір 2027 проходить повні модулі [ІНС1 і ІНС2](/kursy/ins/).
:::

**Мета.** Працюєш у терміналі Linux, ведеш свій проєкт у Git і пишеш документацію в Markdown.

**Хто проходить.** Усі в пілоті, ≈10 год, без пререквізитів. Слот Ф блоку 1 (16.11–13.12.2026, 4 тижні). Хто не склав екстерн ПРГ1, проходить ІНС-експрес у слоті Т блоку 4.

**Власник тем.** Командний рядок, файлова система, SSH, Git, Markdown, технічне письмо. Вікі команди і робота через pull request у пілоті переходять у роботу команди та [ПРГ4](/kursy/prg/#prg4).

**Межі.** Середовище Python (uv, ruff, pytest) налаштовує [ПРГ](/kursy/prg/). Збирання C++ — [ПРГ3](/kursy/prg/#prg3), але WSL2 ставимо тут, і він чекатиме на ПРГ3 у лютому.

## Темп

Діагностика в листопаді ставить тобі мітку темпу.

- **Базовий.** Проходиш усі заняття по черзі.
- **Швидкий** (на діагностиці щонайменше 4 з 5 дій у терміналі без допомоги). У занятті 2 починаєш одразу з контрольних вправ: зробив їх — переходиш до SSH. Звільнений час — на поглиблені завдання Git і на допомогу сусідові.

## Бейдж «Журнал у Git»

Репозиторій зі звітом і CSV твоєї лабораторної [ФІЗ-експрес](/kursy/fiz/ekspres/5-laboratorna/) (хто проходить ІНС-експрес у блоці 4 — з кодом ПРГ2): README, .gitignore, щонайменше 8 змістовних комітів, одна гілка, злита в main. Повна умова — на сторінці [бейджа](/kursy/ins/ekspres/6-beidzh/).

Захист — усний, 10–15 хв, за [рубрикою 0–4](/polozhennia/#рубрика). ШІ-помічники на заняттях вимкнені: команди мають пройти через твої руки (див. [Положення про бейджі](/polozhennia/#ші-помічники)).

## Обладнання і ПЗ

- Шкільний ноутбук з Windows 11. WSL2 потребує увімкненої віртуалізації в BIOS і одноразового налаштування з правами адміністратора — це робить викладач до початку модуля.
- **Флешка академії:** образ Ubuntu 24.04 для WSL з усім потрібним, Git for Windows, VS Code і розширення WSL.
- Інтернет не потрібен. Якщо він є, можна ставити пакунки через apt.

**Якщо WSL2 не стає на ноутбук.** Працюєш у **Git Bash** (входить у Git for Windows): більшість команд модуля там такі самі. Відмінності позначено на сторінках занять. Бейдж і захист — однакові.
