**1 год.** Markdown — простий текст із кількома знаками розмітки. Його читають і люди (як звичайний текст), і GitHub, VS Code, цей сайт (як оформлену сторінку). Уся документація академії — README, звіти, вікі команди — пишеться в Markdown.

## README

README — перший файл, який бачить людина у твоєму репозиторії. Він відповідає на чотири запитання:

1. **Що це?** Одне-два речення.
2. **Що всередині?** Які файли й теки і навіщо.
3. **Як цим користуватися?** Як запустити, відкрити, повторити.
4. **Чиє і коли?** Автор («Ім'я П.»), дата, модуль академії.

```markdown
# Журнал лабораторних

Лабораторні модуля ФІЗ-експрес академії RA97, блок 1, 2026.

## Що всередині

- `svitlodiod/zvit.md` — звіт «Світлодіод під вимірюванням»
- `svitlodiod/r220.csv`, `r470.csv`, `r1k.csv` — серії по 20 вимірів напруги на резисторі

## Як відкрити дані

CSV відкривається в LibreOffice Calc: роздільник — кома, мова — English (USA).

Іван П., листопад 2026.
```

## Технічний текст

- **Пиши для конкретного читача.** Звіт читає викладач, який не стояв поруч. README — однокласник, який завтра продовжить твою роботу.
- **Спершу результат, потім подробиці.** «Струм на 8 % менший за прогноз через падіння напруги USB» — у першому абзаці, а не на останній сторінці.
- **Числа — з одиницями і похибкою.** «6,2 ± 0,3 мА», а не «приблизно 6».
- **Одна думка — один абзац**, короткі речення.
- **Без води.** «У ході виконання даної лабораторної роботи нами було проведено вимірювання» → «Ми виміряли».
- **Перевірені причини, а не здогадки.** «Можливо, через наводки» — здогадка. «Після заміни опорної напруги на виміряну розбіжність зменшилась з 8 % до 1 %» — перевірено.
- **Назви файлів — латиницею, без пробілів**: їх писатимуть у терміналі.

## Вправи

1. Напиши README для тренувальної теки `~/praktyka` з попереднього заняття: що в ній лежить і як її створити заново.
2. Перепиши речення технічною мовою: «Під час проведення експерименту нами було встановлено, що значення струму, отримане в результаті вимірювань, є дещо меншим, ніж те, що було розраховане теоретично».
3. Зроби таблицю з трьома резисторами і струмами з твоєї лабораторної (поки можна з прогнозу) і подивись її в попередньому перегляді.
