**Здача — до останньої п'ятниці блоку** (у пілоті 2026 — до 11.12), захист — ковзний, щойно готовий, з третього тижня блоку.

## Завдання

Веди в Git справжню роботу, а не вправу: репозиторій `zhurnal` з лабораторною [«Світлодіод під вимірюванням»](/kursy/fiz/ekspres/5-laboratorna/). Хто проходить ІНС-експрес у блоці 4, кладе в журнал свій код [ПРГ2](/kursy/prg/#prg2) замість лабораторної.

Історія комітів має показувати, як ішла робота: прогноз, серії вимірів, обчислення, звіт, правки.

## Вимоги

- [ ] `README.md`: що це, що всередині, як відкрити дані, автор («Ім'я П.») і дата.
- [ ] `.gitignore` щонайменше з одним осмисленим правилом (наприклад, тимчасові файли LibreOffice).
- [ ] Звіт лабораторної в Markdown і CSV з даними.
- [ ] **≥ 8 змістовних комітів** з повідомленнями, з яких зрозуміло, що зроблено. Коміти «1», «оновив», «ще» не рахуються.
- [ ] Прогноз закомічено **раніше** за дані вимірювань.
- [ ] Щонайменше **одна гілка, злита в main** (наприклад, гілка для поглибленого рівня лабораторної або для переписування звіту).
- [ ] У репозиторії немає зайвого: тимчасових файлів, копій «звіт (1).md», чужих даних.

## Як здати

Доказ для реєстру бейджів — архів репозиторію **разом із прихованою текою `.git`** (без неї історії немає).

```bash
cd ~
tar -czf zhurnal-ivan-p.tar.gz zhurnal
ls -lh zhurnal-ivan-p.tar.gz
```

Поклади архів у спільну теку академії (куди саме — скаже викладач; з WSL вона видна через `/mnt/…` або Провідник). Власний репозиторій на GitHub — за бажанням, він знадобиться з ПРГ4.

## Критерії

Бейдж приймає будь-який із двох викладачів за [рубрикою 0–4](/polozhennia/#рубрика). Зараховано, коли кожен критерій ≥ 2.

| Критерій | Що перевіряємо |
| --- | --- |
| Репозиторій | усі вимоги зі списку вище виконано |
| Історія | коміти змістовні, по одній зміні, повідомлення зрозумілі; видно, як ішла робота |
| Документація | README відповідає на чотири запитання; звіт читається без автора поруч |
| Розуміння | відповіді на запитання про Git, SSH і термінал — своїми словами |
| Термінал наживо | завдання викладача виконано в терміналі, без мишки і без ШІ |

## Захист

10–15 хв. Викладач запитає, зокрема:

- чим коміт відрізняється від збереження файлу;
- що потрапляє в `.gitignore` і чому;
- навіщо ключ SSH замість пароля.

Потім — завдання наживо в терміналі, на кшталт:

- знайти всі CSV у теці й порахувати в них рядки одним конвеєром;
- відкотити зміну файлу, якої ще немає в коміті;
- розв'язати конфлікт злиття, який підготував викладач у твоєму репозиторії.
