# ІНС-експрес · тренувальна тека

Скрипт для заняття 2 «Термінал і файлова система» модуля ІНС-експрес академії RA97.
Пояснення і вправи: https://roboticsacademy97.github.io/kursy/ins/ekspres/2-terminal/

```bash
bash stvoryty-praktyku.sh
cd ~/praktyka
```

Скрипт створює теку `~/praktyka` з лабораторними CSV, журналами робота й кількома «пастками» для вправ.
Якщо тека вже є, скрипт нічого не чіпає.
