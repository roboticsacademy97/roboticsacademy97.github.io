# ФІЗ-експрес · Arduino як вольтметр

Готовий скетч для занять 4–5 модуля ФІЗ-експрес академії RA97.
Умова і пояснення: https://roboticsacademy97.github.io/kursy/fiz/ekspres/4-arduino/

1. Відкрий `voltmetr/voltmetr.ino` в Arduino IDE 2.
2. Обери плату (Arduino Uno або Arduino Nano) і порт.
3. У блоці «Налаштування» впиши `UREF_MV` — напругу між пінами 5V і GND, виміряну мультиметром, у мілівольтах.
4. Завантаж скетч, відкрий Serial Monitor (115200 бод) і надішли будь-який символ — отримаєш серію вимірів у форматі CSV.

Код скетча не міняй, лише константи. Модельні дані для роботи без плати — у теці `dani/`.
