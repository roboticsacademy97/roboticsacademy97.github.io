# Модельні дані для лабораторної «Світлодіод під вимірюванням»

Ці дані **згенеровані програмно** для тренування, а не виміряні в майстерні. Ними користуються, коли немає плати
або зв'язку з нею. Обчислення похибки, звіт і захист — такі самі, як зі справжніми даними; у звіті напиши, що дані модельні.

Схема: 5V → червоний світлодіод → резистор R → GND, A0 — між світлодіодом і резистором (напруга на резисторі).
Скетч `voltmetr.ino` з `UREF_MV = 4860`.

| Файл | Номінал R | R, виміряний мультиметром | U_R мультиметром |
| --- | --- | --- | --- |
| `r220.csv` | 220 Ом ± 5 % | 218 Ом | 2,86 В |
| `r470.csv` | 470 Ом ± 5 % | 466 Ом | 2,90 В |
| `r1k.csv` | 1 кОм ± 5 % | 985 Ом | 2,94 В |

Напруга між 5V і GND, виміряна мультиметром: 4,86 В.
Світлодіод: у даташиті падіння напруги 2,0 В (типове) при 20 мА.
Мультиметр: похибка ±(0,5 % + 2 одиниці останнього розряду) на межі 20 В, ±(0,8 % + 2) на межі 2 кОм.
