# Ровер на сітці

Шаблон завдання бейджа ПРГ1 (Python I) Академії робототехніки 97. Він же — домашнє завдання діагностики пілотного набору 2026.

Повна умова, терміни і правила захисту: <https://roboticsacademy97.github.io/kursy/prg/rover-na-sitci/>

## Що в теці

| Файл | Що це |
| --- | --- |
| `rover.py` | заготовки функцій — тут ти пишеш код |
| `tests/test_1_obovyazkovyi.py` | тести обов'язкового рівня: для бейджа мають пройти всі |
| `tests/test_2_*.py`, `tests/test_3_*.py` | тести поглибленого рівня і рівня зі зірочкою: пропускаються, доки функцію не написано |
| `pyproject.toml`, `uv.lock` | версія Python, pytest і ruff — для `uv` |

Тести не змінюй: викладач запускає свою копію.

## Як запустити

Потрібні [uv](https://docs.astral.sh/uv/) і VS Code з розширеннями Python і Ruff. Відкрий у терміналі цю теку й виконай:

```sh
uv run pytest        # усі тести; перший запуск сам поставить Python 3.13, pytest і ruff
uv run ruff check .  # перевірка стилю: має бути «All checks passed!»
uv run rover.py      # запустити ровер вручну
```

Без інтернету `uv` бере пакети з офлайн-кешу на флешці академії. Якщо `uv` поставити не вдалося, підійде Python 3.13+ і `python -m pytest` з тієї ж флешки.

## Що здавати

Лише файл `rover.py` — у свою теку в спільній папці академії до терміну на сторінці умови.
