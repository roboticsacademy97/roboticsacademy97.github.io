# Як змінити сайт

1. Створіть гілку від актуального `main`: `git switch -c kursy/fiz-pasport`.
2. Змініть файли. Текст сторінок — Markdown у `src/content/docs/`, дані програми — YAML у `src/data/`.
3. Перевірте: `npm run build`. Якщо впала перевірка програми, вона пише, який модуль і чому.
4. Коміт українською, коротко: «Розділ: що зроблено», наприклад «Карта: МЕХ3 потребує МАТ2.1».
5. Відкрийте pull request за шаблоном і попросіть іншого викладача переглянути.
6. Після злиття сайт оновиться за 1–2 хвилини (вкладка Actions).

## Типові зміни

- **Новий пререквізит або перенесення модуля** — `src/data/modules.yaml` (поле `prereqs`) і, якщо змінюється шлях, `src/data/plan-a.yaml`. Карта і сторінки курсів оновляться самі.
- **Паспорт курсу** — нова сторінка `src/content/docs/kursy/<slug>/index.mdx` (зразок — `kursy/prg/`) і `passport: v0.1` у `courses.yaml`.
- **Матеріали модуля** — у теці курсу: `src/content/docs/kursy/<slug>/<slug модуля>.md`.
